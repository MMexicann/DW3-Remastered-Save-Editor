# Unregistered format research

Read the [root guide](../../../AGENTS.md). Candidate codecs and read-only native
inspection live here, separated by game. A working cipher or fingerprint does
not qualify gameplay identity, integrity or writable fields.

Document native facts, supported variants, source licences and exact missing
inputs in [docs](../../../docs/README.md). Preserve unknown bytes and keep no-op
operations byte-exact. Do not disable integrity flags or repair damaged input.

Do not execute game binaries or distribute private inputs, analysis images,
extracted catalogs, owner context or player saves. Promote a candidate into a
registered game package only after the format/editor and required tests qualify.
