# Runtime metadata

Read the [root guide](../../../AGENTS.md). JSON here is reviewed runtime metadata
packaged with the application. Preserve schema/version compatibility and use the
package's resource loading in source and frozen builds.

Names, IDs, bounds and prerequisites require game-specific evidence. Do not
assign another edition's roster order or import restricted extracted catalogs.
Never add player saves, account identifiers, private paths or game assets.

Support changes must agree with the registry, canonical supported-game inventory,
README, generated document and tests. Coordinate manifest/hash changes.
